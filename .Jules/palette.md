## 2024-05-18 - Menu Bar Keyboard Navigation
**Learning:** MacOS Menu Bar applications often lack standard keyboard shortcuts, forcing users to click through menus for frequent actions like resizing or quitting. This reduces accessibility for power users.
**Action:** Always add standard keyboard shortcuts (e.g., `⌘Q` for Quit, `⌘+`/`⌘-` for scale) to Menu Bar actions to improve keyboard accessibility and provide a native feel.
