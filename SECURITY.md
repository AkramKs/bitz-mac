# Security Policy

## Supported Versions

Only the latest release and the current `main` branch receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of Bitz seriously. If you believe you have discovered a security vulnerability:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability via GitHub Private Vulnerability Reporting at:
   https://github.com/AkramKs/bitz-mac/security/advisories/new
   Or email the maintainers directly.
3. Please include:
   - Description of the vulnerability and its potential impact.
   - Clear steps or a proof of concept to reproduce the issue.
   - Any suggested mitigations or fixes if available.

We will acknowledge receipt within 48 hours and work with you on a resolution before any public disclosure.
